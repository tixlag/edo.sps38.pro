# Обучение и подготовка данных

Скрипты перенесены как исследовательские инструменты. Runtime сервисов их не импортирует. Большие датасеты, разметка и результаты обучения не переносились.

Пути в скриптах и YOLO/Paddle конфигурациях относятся к исходной исследовательской машине; перед использованием задайте свои пути и отдельное окружение. Автоматическое переобучение не является частью установки сервиса. Runtime `requirements.lock` не гарантирует запуск всех архивных обучающих экспериментов.
