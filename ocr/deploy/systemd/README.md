# Шаблоны systemd

Шаблоны используют `/opt/edo.sps38.pro/ocr` и пользователя `ocr`. Перед установкой замените путь, User и Group на свои значения. Пользователю нужны чтение моделей и запись в `var`. Окружения создаются через `scripts/setup_service.sh`, параметры — в `.env` соответствующего сервиса.

Не устанавливайте новую службу на занятый порт. Переключение с действующих служб выполняется отдельно после проверки на временных портах; эти шаблоны автоматически ничего не останавливают и не включают.

Постоянные службы: `recognize-ru.service` и `recognize-uz.service`. Прежняя `doc-recognizer.service` объявлена legacy: она остановлена, отключена и замаскирована. Порядок переключения и фактическое размещение — в `../../docs/operations.md`.

Для CI/CD используйте `../runner/install_host.py` и начальную подготовку из `../../docs/ci-cd.md`: службы будут указывать на управляемый current, а MODELS_ROOT — на постоянные частные модели. Установщик требует уже проверенный baseline и сохраняет закрытые резервные копии.
