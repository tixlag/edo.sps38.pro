# Шаблоны systemd

Шаблоны используют `/opt/document-ocr` и пользователя `ocr`. Перед установкой замените путь, User и Group на свои значения. Пользователю нужны чтение моделей и запись в `var`. Окружения создаются через `scripts/setup_service.sh`, параметры — в `.env` соответствующего сервиса.

Не устанавливайте новую службу на занятый порт. Переключение с действующих служб выполняется отдельно после проверки на временных портах; эти шаблоны автоматически ничего не останавливают и не включают.
