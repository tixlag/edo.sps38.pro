# Демонстрация этапов кандидата

`candidate-stage-motion.tsx` — синтетический пример для
[`candidate-stage-motion.gif`](../gifs/candidate-stage-motion.gif). Он использует
реальный `CandidateStageAccordion`, но не подключается к данным кандидатов.
Исходник не входит в приложение; для записи он загружается в отдельную локальную
Vite-страницу с CSS сборки web и заглушками запросов миниатюр.

Прежний исходник находился только в игнорируемом `.cache/cards-preview/main.tsx`.
Именно в нём название отсутствующего документа было задано строкой
«Документ ещё не загружен». В примере теперь используются конкретные названия
«ИНН» и «СНИЛС». В рабочем API название отсутствующего документа и раньше
возвращалось из `DocumentType.title`, синхронизированного с каталогом ERP.

Счётчики соответствуют карточкам: в каждом этапе один имеющийся документ
(одобренный либо черновик) и один отсутствующий. На этапе 7 дополнительно
показана одобренная карта тахографа с ошибкой отправки; ошибка доставки
учитывается отдельно от подтверждения документа.
